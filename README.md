# Планировщик трат — Управление личным бюджетом

Мобильное приложение для Android для учёта личных финансов, контроля бюджета и аналитики трат.

## Возможности

### Основные функции
- Добавление трат (сумма, категория, комментарий, дата)
- Умный ввод суммы (поддержка "к" и "т" — 1.5к = 1500, 2т = 2000)
- Просмотр всех трат в одном списке
- Поиск по комментариям
- Удаление и отметка выполненных трат (долгое нажатие)
- Детальный просмотр траты с цветными кнопками

### Управление бюджетом
- Установка общего бюджета на месяц (с проверкой лимита 10 млн ₽)
- Редактирование бюджета для каждой категории отдельно
- Добавление и удаление своих категорий
- Визуальные прогресс-бары с цветовой индикацией:
  - Зелёный - до 80% бюджета
  - Оранжевый - 80-100%
  - Красный - превышение
- Круговая диаграмма трат по категориям (только за текущий месяц)
- Вертикальные названия категорий на диаграмме

### Цели накоплений (сбережения)
- Создание целей накоплений (название, целевая сумма, иконка)
- Пополнение сбережений
- Визуальный прогресс для каждой цели
- Удаление целей

### Регулярные платежи (напоминания)
- Создание регулярных платежей (название, сумма, категория, число месяца)
- Автоматическое напоминание в указанный день
- Быстрое добавление траты из напоминания

### Аналитика по месяцам
- Переключение между месяцами (кнопки ◀ ▶)
- Круговая диаграмма трат за выбранный месяц
- Статистика: сумма трат, среднее в день, самая затратная категория

### Экспорт данных
- Экспорт всех трат в CSV файл с диалогом подтверждения
- Правильная кодировка UTF-8 для русского языка

### Справка и лимиты
- Встроенная справка с инструкцией по использованию
- Лимиты:
  - Максимальная сумма траты: 10 000 000 ₽
  - Бюджет категории: 10 000 000 ₽
  - Общий бюджет: 10 000 000 ₽
  - Сумма цели: 10 000 000 ₽
  - Пополнение цели: 10 000 000 ₽
  - Комментарий: до 12 символов
  - Название категории: до 15 символов
  - Название цели: до 20 символов

### База данных
- Автосохранение через Room Database
- Все данные сохраняются локально

## Сохранение данных

Все данные автоматически сохраняются в базе данных Room. При повторном запуске бюджет, траты, цели и регулярные платежи загружаются автоматически.

## Технологии

- Kotlin - язык программирования
- Room Database - локальное хранение данных
- Coroutines - асинхронность
- MPAndroidChart - круговые диаграммы
- Material Design - интерфейс
