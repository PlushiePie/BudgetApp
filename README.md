# Планировщик трат — Управление личным бюджетом

Мобильное приложение для Android для учёта личных финансов, контроля бюджета и аналитики трат.

## Возможности

### Основные функции
- Добавление трат (сумма, категория, комментарий, дата)
- Умный ввод суммы (поддержка "к" и "т" — 1.5к = 1500, 2т = 2000)
- Просмотр всех трат в одном списке
- Поиск по комментариям
- Удаление и отметка выполненных трат (долгое нажатие)

### Управление бюджетом
- Установка общего бюджета на месяц
- Редактирование бюджета для каждой категории отдельно
- Визуальные прогресс-бары с цветовой индикацией:
  - Зелёный - до 80% бюджета
  - Оранжевый - 80-100%
  - Красный - превышение
- Круговая диаграмма трат по категориям

### Сбережения (цели накоплений)
- Создание целей сбережений (название, целевая сумма, иконка)
- Пополнение сбережений
- Визуальный прогресс для каждой цели
- Удаление целей

### Аналитика и прогнозы
- Средние траты - в день, неделю, месяц
- Самая затратная категория - сумма и процент от всех трат
- Прогноз на конец месяца - сколько останется денег
- Статистика по текущему месяцу

### Экспорт данных
- Экспорт всех трат в CSV файл (совместимо с Excel)
- Правильная кодировка UTF-8 для русского языка

### База данных
- Автосохранение через Room Database
- Все данные сохраняются локально

## Сохранение данных

Все данные автоматически сохраняются в базе данных Room. При повторном запуске бюджет, траты и цели сбережений загружаются автоматически.

## Технологии

- Kotlin - язык программирования
- Room Database - локальное хранение данных
- Coroutines - асинхронность
- MPAndroidChart - круговые диаграммы
- Material Design - интерфейс
